PBWM Working Memory Project 

This project is built on the emergent projects - see https://github.com/emer and follow installation instructions 

This project codebase was used for the paper: https://elifesciences.org/reviewed-preprints/97894

The main model files are the sir{} files. The number tells the set size and the chunk/no chunk annotates if there that model build includes a chunk layer. The reason for this division/redundancy was to allow for
parallel parameter searches and parallel experiments. 

The analysis folder includes many jupyter lab notebooks that do various analyses.
